Software engineering is the Observatory's first domain because it is where AI-produced work is most visible today and
where the effects can be measured in public evidence. Examples include changes in open-source activity, published
developer surveys, hiring and job-posting data, and documented changes in engineering practice.

This case study is in its planning stage. The signals below are what it will track. Each one stays empty until there is
public evidence to fill it.
